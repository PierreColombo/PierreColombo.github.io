Ce que la revue établit

Le gate de rétention décide de tout, et presque personne ne le mesure. Sans contrôle de généralisation, l'optimisation automatique d'un scaffold tombe sous sa ligne de base. Un seuil d'acceptation mesuré a ~40 % de faux positifs.

Un taux d'erreur agrégé ne spécifie pas un vérifieur ; la structure du biais si. Un taux de faux positifs initial de 2 % peut détruire un modèle, et un vérifieur deux fois moins erroné peut faire deux fois pire. Les faux positifs coûtent jusqu'à −91,5 points, les faux négatifs au pire −13,5.

Ensembler des juges ne corrige pas l'erreur commune. Moyenner davantage de juges du même cohorte converge vers l'erreur partagée — et les paires les plus corrélées sont inter-fournisseurs, pas intra-famille.

Valider un vérifieur par dégradation délibérée. 603 vérifieurs sur 603 passent un contrôle de bon sens ; 0 sur 38 font échouer le document dont le chiffre décisif a été corrompu.

Les contre-transferts sont mieux établis que les transferts. Entraîner sur un domaine et déployer sur un autre est documenté comme nocif, pas neutre ; le transfert cross-domaine d'une compétence apprise par RL n'est établi nulle part.

Comment lire

evidence est une somme de six cases binaires — baselines appariées, ablation isolante, variance rapportée, cohérence abstract/tableaux, éval fiable, reproductibilité — et n'est comparable qu'entre papiers de même type : une taxonomie ne peut pas avoir de seeds. La grille note ce qui est établi, pas ce qui est avoué.

Chaque mémo contient une section 7.0 qui confronte chaque chiffre de l'abstract à sa source dans le papier, avec un verdict : confirmé, contredit, introuvable, ou sur-généralisé.

Corpus = échantillon de convenance : onglets de départ, puis une recherche arXiv sur 6 mois filtrée à 85 %, puis les billets d'une seule entreprise. Les régularités valent pour ces mémos, pas pour le champ.
